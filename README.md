# Jennifer - Assistente Personale con Integrazione Google Drive

Jennifer è un'assistente virtuale personale basata sull'intelligenza artificiale di Google Gemini, con accesso sicuro in scrittura e lettura al proprio account Google Drive per la persistenza a lungo termine di chat e ricordi personali.

## Caratteristiche principali
* **AI Engine**: Integra Google Gemini 3.5 Flash per risposte fluide ed intelligenti in italiano.
* **Memoria Persistente (Compounding Knowledge)**: Salva concetti, ricordi e passioni dell'utente all'interno del proprio Google Drive, rievocandoli automaticamente nelle chat future.
* **Vocale Integrato**: Consente di comunicare a voce tramite sintesi e riconoscimento vocale nativi del browser.
* **Zero Backend**: Gira completamente nel browser, garantendo che le chiavi e i dati rimangano di esclusiva proprietà dell'utente.

## Come usarlo localmente
1. Clona questo repository.
2. Avvia il server locale con:
   ```bash
   python3 server.py
   ```
3. Naviga su `http://localhost:8000`.
4. Configura il tuo **Google Client ID** seguendo le istruzioni grafiche incluse.
